# Teacher's Guide: TRACK Attendance System

## Quick Start Guide for Kiwalan National High School Teachers

---

## 📋 Overview

The TRACK attendance system allows you to:
- Create attendance sessions for your classes
- Mark students present, absent, late, or excused
- View and edit attendance records
- Track attendance patterns

---

## 🚀 Taking Attendance (Step-by-Step)

### Method 1: Quick Attendance (All Present)

Best for classes where most students are present:

1. **Create a Session**
   - Click the **"New attendance session"** button
   - Select your class from the dropdown
   - Choose today's date
   - Click **"Create session"**

2. **Mark All Present**
   - The session opens automatically
   - Review the student roster
   - Click **"Mark all present"** button at the top
   - Confirm the action
   - Wait for "All students marked present" message

3. **Adjust Exceptions**
   - Find absent students in the list
   - Click **"Absent"** button for each
   - Do the same for **"Late"** or **"Excused"** students
   - Each change saves automatically

4. **Done!**
   - Review the status summary at the top
   - Click **"Close"** when finished

---

### Method 2: Individual Marking

Best for smaller classes or when attendance varies:

1. **Create a Session** (same as Method 1)

2. **Mark Each Student**
   - Scroll through the student list
   - For each student, click their status:
     - **Present** - Student is in class
     - **Absent** - Student is not in class
     - **Late** - Student arrived after start time
     - **Excused** - Student has valid excuse
   - Watch for "Attendance saved" message after each click

3. **Check Your Progress**
   - Look at the summary at the top
   - Unmarked students shown in gray badge
   - Continue until "0 Unmarked"

4. **Done!**
   - Click **"Close"** when all students marked

---

## 🔍 Finding Past Sessions

### Use Filters to Search:

**Filter by Class:**
- Click the "All classes" dropdown
- Select specific class (e.g., "Mathematics — Grade 7 Sampaguita")
- Sessions list updates automatically

**Filter by Date:**
- Click the date picker
- Select a specific date
- Only sessions from that date shown

**Clear Filters:**
- Click the **X** button next to filters
- All sessions reappear

---

## ✏️ Editing Attendance

You can change attendance records anytime:

1. Find the session using filters
2. Click **"Take attendance"** button
3. Find the student you need to change
4. Click the new status (Present, Absent, Late, Excused)
5. Change saves immediately
6. Click **"Close"** when done

**Note:** Previous status is automatically replaced - no duplicate records created.

## ⚠️ Common Situations

### "A session for this class on this date already exists"

**What it means:** You already created attendance for this class today.

**What to do:**
- Find the existing session in the list
- Click "Take attendance" to view/edit it
- If you need to take attendance for a different period, add a note (e.g., "Afternoon session")

### Student is absent but has a doctor's note

**What to do:**
- Mark student as **"Excused"** (blue button)
- This counts as an explained absence
- The principal can see the distinction in reports

### Student arrived 10 minutes late

**What to do:**
- Mark student as **"Late"** (amber/yellow button)
- This tracks punctuality separately from absences

### Student left early

**What to do:**
- Mark as **"Present"** if they attended majority of class
- Mark as **"Excused"** if they had permission
- Add a note in the session if needed

### Made a mistake

**What to do:**
- Just click the correct status button
- The system updates immediately
- No need to delete or cancel

## 📊 Reading the Summary

At the top of the attendance screen, you'll see:

```
15 students  |  13 Present  |  1 Absent  |  1 Late  |  0 Unmarked
```

- **Total students** - Enrolled in this class
- **Present** (green) - In class
- **Absent** (red) - Not in class
- **Late** (amber) - Arrived after start
- **Excused** (blue) - Valid absence reason
- **Unmarked** (gray) - Status not yet selected

**Tip:** Aim for "0 Unmarked" before closing the session.

## 💡 Tips & Best Practices

### DO:
✅ Take attendance within the first 10 minutes of class
✅ Use "Mark all present" for efficiency, then fix exceptions
✅ Mark late students as "Late" not "Absent"
✅ Use filters to find specific sessions quickly
✅ Review the summary before closing the session

### DON'T:
❌ Create multiple sessions for the same class/date
❌ Mark students present if they're not in class
❌ Wait until end of day to record attendance
❌ Forget to mark late arrivals
❌ Leave sessions with unmarked students

## ❓ Troubleshooting

### Problem: Can't see my class in the dropdown

**Solution:**
- Check with the administrator
- Your class assignment may not be set up yet
- Or you're looking at the wrong school year

### Problem: Student appears twice in the list

**Solution:**
- Student may be enrolled in multiple sections
- Contact administrator to verify enrollment
- Mark attendance for the correct section

### Problem: "Mark all present" takes a long time

**Solution:**
- Large classes (35+ students) take 10-15 seconds
- Wait for "All students marked present" message
- Don't close the window until complete
- Consider marking smaller groups individually

### Problem: Filter shows "0 of 12 sessions"

**Solution:**
- Click the **X** button to clear filters
- You may have selected a date with no sessions
- Or selected the wrong class

### Problem: Session won't create

**Solution:**
- Check that you selected both class AND date
- Ensure date is not in the future
- Try refreshing the page
- Contact administrator if problem persists
